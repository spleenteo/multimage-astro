## The slice, decided here
- **The client sends only `{id, qty}` per line**; titles and prices come from the CDA. The answer carries amounts in cents: `{ ok:true, copySent, lines:[{id,title,qty,priceCents,amountCents}], copies, shipping, shippingKind, total, dropped:[id] }`. The page compares its own bag snapshot with `lines` to name dropped and repriced books.
- **Error bodies are `{ ok:false, error:<code>, fields?:[key] }`**, codes only: 405 `method_not_allowed`; 400 `bad_request` (not JSON / not an object), `too_large` (over 16384 bytes), `empty_bag`, `too_many_lines` (>30), `bad_lines` (id not `^[A-Za-z0-9_-]{1,40}$`, qty not an integer 1–20, duplicate id), `invalid` (+ field keys), `turnstile` (missing, or siteverify said no); 409 `nothing_orderable` (every line dropped); 502 `turnstile_unavailable`, `catalogue_unavailable`, `send_failed`; 503 `not_configured`. Checks run in that order, config first, so a bare POST in production answers 503 (Done 8).
- **The endpoint sets `cache-control: private, no-store` on every answer itself** (as `invalidate-cache` does): the middleware only does it when the cache provider exists (Cloudflare), and Done 10 is also checked in dev. Middleware and `src/worker.ts` stay untouched.
- **Turnstile**: page key = `PUBLIC_TURNSTILE_SITE_KEY`, else in dev `1x00000000000000000000AA`, else none (mailto fallback, no form). Secret = `TURNSTILE_SECRET_KEY`, else in dev `1x0000000000000000000000000000000AA`. siteverify must give `success`, `hostname` = the request's hostname and `action` = `ordine`; the hostname and action checks are skipped only when `import.meta.env.DEV` and the secret matches `^\dx0+AA$` (Cloudflare test keys answer with dummy values). `api.js?render=explicit` is injected by the page script only when the form shows; the widget is reset after every failed send (tokens are single-use).
- **Mail**: `RESEND_API_KEY` set → `fetch('https://api.resend.com/emails')`, Bearer, JSON `{from: ORDER_FROM, to:[…], reply_to, subject, text}`, `AbortSignal.timeout(10000)`. First to ordini@ (failure → 502 `send_failed`, the page offers the mailto), then the copy to the visitor (its result is `copySent`). Dev with no key: the email texts go to the console and `copySent` is true. Outside dev, a missing key → 503. Logs: one line per answer, `[ordine] <status> <code>` plus `lines= dropped= copySent=` on 200; never a body, name, address or email.
- **Authors**: the CDA author has `fullName` and `alias`, not `name` (`schema.ts:58,67`): the query selects both and the endpoint maps them with `getAuthorDisplayName(a, '')` from `src/lib/authors.ts` (empty names are filtered out before `join(', ')`) before calling the pure rebuild.
- **The page's "Modifica la borsa" calls `openBag(button)`**, it carries no `data-bag-open`: the drawer script rewrites the `aria-label` and `hidden` of every `[data-bag-open]` (`drawer.client.ts:143`).
- **Widths at 390px** (container content 390 − 2×24 = 342px). "Ordini come", four cells at 0.875rem with 14px padding: ≈80+78+118+86+borders ≈ 367 > 342, so a 2×2 grid below 640px and four in a row from 640px. The two-field rows (email/telefono, CAP e città/provincia) stack below 640px; from 640px `1fr 1fr` and `1fr 7rem`. The bank box (aside padding 20px, box 16px) leaves 270px: the dl stacks below 640px and the grouped IBAN (≈257px) wraps only at its spaces. Turnstile `size:'flexible'` fills the column. Success actions wrap (≈170+12+170 > 342). The 44px goes on the controls (inputs, radio and checkbox rows, segmented labels, text buttons), never on a bordered group; inputs are `h-11 lg:h-10` (DESIGN Inputs).
- **Contrast**: slate on mist is under 4.5:1, so small text inside the mist aside is charcoal; slate only on white.
- **No sticky aside**: with the steps and the bank box it is taller than a laptop viewport.
- **Tests (essential)**: the logic is in pure `order.ts` functions, checked by `npx tsx "$TMPDIR/borsa-V2/order-check.ts"` (absolute import, `node:assert/strict`); the endpoint by curl on a dev server (T3, T6); fail-closed by a production-mode build (T6). Scripts and logs live in `$TMPDIR/borsa-V2/`, removed at the end with `python3 -c 'import shutil,sys;shutil.rmtree(sys.argv[1])' "$TMPDIR/borsa-V2"`. Dev servers use a free port (`lsof -nP -iTCP:<port> -sTCP:LISTEN` prints nothing; never 4321, 4322, 4329, 5198), `RESEND_API_KEY= TURNSTILE_SECRET_KEY= PUBLIC_TURNSTILE_SITE_KEY= npx astro dev --ignore-lock --port <port>` (empty overrides in the process env: no real email can leave and the test keys apply), are stopped after, then `git diff --quiet -- schema.ts || git checkout -- schema.ts`.
