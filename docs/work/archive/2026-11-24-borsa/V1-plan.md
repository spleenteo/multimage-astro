## The slice, decided here
- **`order.ts` imports nothing** (no `books.ts`, `colors.ts` or `~/` alias), so client scripts can bundle it and plain `npx tsx` can load it. It has its own `it-IT` EUR formatter (`minimumFractionDigits: 2`, as in `formatBookPrice`), exported; T2 makes `formatBookPrice` use it and deletes `euroFormatter` in `books.ts`. `books.ts` imports from `order.ts`, never the reverse.
- **Two rules, each written once.** `isPrintInCatalogue({archive, format})`: not archived, and the format (trimmed, case-insensitive) is not `ebook`. It decides the mailto and the shipping terms. `isOrderablePrint({archive, format, price})` also needs a finite numeric price, and decides "Metti in borsa". A print book with no price keeps the mailto (Done 9).
- **Store**: `src/lib/bag.client.ts` (`.client.ts` = browser-only, as `catalogue.client.ts`). The stored value is `{"v":1,"items":[…]}`. Bad JSON, a missing `v` or a bare array resets the bag to empty and is rewritten. Items go through `toBagItem`, and invalid ones are dropped. If localStorage throws, the bag lives in memory. `window` is touched only inside functions. Scripts init when the module runs (no ClientRouter); a `data-*-ready` flag makes a second init a no-op.
- **One JSON attribute, `data-bag-item`,** carries the `BagBook` (a `BagItem` without `qty`). The server serialises it and the script validates it with `toBagItem`. Thumb `<url>?w=120&fit=max&auto=format`, tint `coverFieldPalette(colors).field`, authors joined with `, `.
- **The no-JS fallback is two siblings.** The mailto `Button` is visible, "Metti in borsa" sits in a `hidden` span, and the script swaps them. `Button`'s API is unchanged. The wrappers use `display: contents`, so `.actions` still lays the children out. In Tailwind 4 preflight, `[hidden]` is `display:none !important`, which beats `md:inline-flex`.
- **The drawer DOM is built from a `<template>` with `textContent`/`setAttribute`, never `innerHTML`**: titles come from the CMS, and the stored value can be edited. The header buttons hold no logic: the drawer script reveals them, fills the count, sets the `aria-label` ("Borsa" or "Borsa, N copie") and opens the drawer on click. The header's inline script is untouched.
- **Tests (essential)**: no test file, since no sensitive area is touched. Throwaway `npx tsx` scripts check T1 and T3. They live in `$TMPDIR/borsa-V1/`, outside the repo, and are deleted at the end with `python3 -c 'import shutil,sys;shutil.rmtree(sys.argv[1])' "$TMPDIR/borsa-V1"`.

## Deviations from the mandate
- V1's `order.ts` holds only the facts V1 uses: ordini@, the cap of 20 and the storage key. IBAN, BIC, intermediary SWIFT, PayPal and the shipping kinds and fee arrive in V2 with their first reader, so V1 leaves no dead exports.

- The navy "oppure scrivici un'email" link is on the book page only; the home hero keeps its "Altri modi per averlo" list.
