## The slice, decided here
- **Code clash**: `saveWithCodeRetry(insert, first, next)` in `order.ts` (still import-free, so tsx tests it) calls `insert(first)`; when the error is a clash (`isCodeClash`: `err.message` or `err.cause.message` matches `/UNIQUE constraint failed: orders\.code/`) it calls `insert(next())` once; any other error or a second failure gives `saved: false`. It never logs or rethrows. The endpoint logs `[ordine] code_clash` on a retry and keeps `save_error` on a failure; a double clash (odds ~1e-12) falls back to the V4 "mailed, not saved" path.
- **PDF model** (`orderPdf(input)` → `{ filename, title, blocks }`, blocks `{ kind: 'brand'|'meta'|'heading'|'text'|'row'|'total'|'rule'; text; right? }`), in order: brand "Multimage"; meta "Associazione Multimage · ordini@multimage.org"; heading "Richiesta d'ordine <code>"; meta the date in Italian, `Europe/Rome` ("25 novembre 2026"); if `!notified` a text "L'avviso a Olivier non è partito: scrivi a ordini@multimage.org indicando il codice." (lesson on degraded flags); heading "Spedizione a": name, address, "<city> (<province>)", "Email: …", "Telefono: …" only when given, "Ordini come: <BUYER_KINDS label>"; heading "Libri": one row per line `<title> · <copiesLabel> × <price>` / amount; rule; rows "Copie", "Spedizione: <label>"; total "Totale a prezzo di copertina"; heading "Note" + text only when notes exist; heading "Cosa succede dopo": three numbered texts (confirmation within two working days; pay by bank transfer or PayPal, causale "Ordine libri <code>"; send the receipt to ordini@); heading "Pagamento": Intestato a, Banca, IBAN (`formatIban`), BIC, Banca intermediaria (SWIFT), PayPal, `Causale: Ordine libri <code>`; meta "I tuoi dati restano allo staff solo per il tempo necessario alla spedizione." Filename `ordine-<code>.pdf`, title `Ordine <code>`.
- **WinAnsi only**: every string passes `pdfText()` (U+2000–U+200B, U+202F, U+205F → space; control characters dropped; anything above U+00FF outside `€…‘’“”–—•` → `?`), because jsPDF's built-in Helvetica is WinAnsi (spike C). No custom font, no `html()`, so jsPDF's optional deps never load.
- **Renderer**: A4 portrait, mm, 18 mm margins, Helvetica; brand bold 18 pt, heading bold 12 pt with 5 mm before, text/meta 10 pt (meta in grey 90), rows wrap the left text with `splitTextToSize` to width − 35 mm and right-align the amount, total bold 12 pt, rule a 0.2 mm line; a block that would cross the bottom margin starts a new page. `renderOrderPdf(pdf): jsPDF`, `saveOrderPdf(input)` = `renderOrderPdf(orderPdf(input)).save(filename)`.
- **Lazy load**: the page script calls `await import('./_order-pdf.client')` on tap; nothing from `jspdf` or `order-pdf` is imported statically by `_order-page.client.ts`, so `/borsa` pays nothing until the tap.
