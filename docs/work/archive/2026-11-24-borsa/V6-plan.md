## The slice, decided here
- **Rule**: `memberDiscount(subtotal) = Math.round(subtotal * MEMBER_DISCOUNT_PERCENT / 100)` (half up to the cent; 1599 → 480, 5 → 2); `total = subtotal − discount + shipping`. `subtotal_cents` stays the books at cover price; `total_cents` is after discount. Any buyer kind may tick the box: the staff sorts it out.
- **Trust**: the client sends only `member` (a boolean, `o.member === true`; `"true"` is false); the server computes the discount from the rebuilt lines. A `discount` or `total` in the body is ignored, as prices already are.
- **Shared strings in `order.ts`** (no repetition): `MEMBER_DISCOUNT_LABEL = \`Sconto soci −${MEMBER_DISCOUNT_PERCENT}%\`` (U+2212), `MEMBER_LINE = 'Socia/socio: sì'`, `formatDiscount(c) = \`−${formatCents(c)}\``, `orderTotalLabel(member)` → `'Totale con sconto soci'` or `'Totale a prezzo di copertina'` (with the discount the cover-price label would be false).
- **Unticked = as before** (Done 3): no member line, no discount line, the old labels everywhere. Member line and discount appear only when `member` is true.
- **Email**: `Socia/socio: sì` right after `Ordini come: …`; `Sconto soci −30%: −9,60 €` right after `Copie: …`; last line `${orderTotalLabel(member)}: …`.
- **Recap**: a row `<div data-order-discount-row hidden><dt>{MEMBER_DISCOUNT_LABEL}</dt><dd data-order-discount></dd></div>` between "Copie" and "Spedizione" (Tailwind v4 preflight's `[hidden] { display: none !important }` beats `.order-totals div { flex }`); the total `dt` gets `data-order-total-label`. The size line uses the discounted total. On the checkbox's `change` the existing polite region says `<total label>: <total>`.
- **Form**: the row sits after the "Ordini come" fieldset, before the notes: `.order-member > label.order-check` (44px row, existing) with `<input type="checkbox" id="order-member" aria-describedby="order-member-hint">` (no `name`, no `required`) and `<span>Sono socia o socio di Multimage</span>`, then `<p class="order-hint-line order-member__hint" id="order-member-hint">Sconto del {MEMBER_DISCOUNT_PERCENT}% sul prezzo di copertina: lo staff verifica l'iscrizione.</p>`. No fixed-width row is added (lesson on row sums: not applicable).
- **Success**: when `res.member`, two more `li` after the book lines: `Socia/socio: sì` and `Sconto soci −30% · −9,60 €`; the total label reads `Totale con sconto soci · <shipping>` (unticked keeps `Totale · <shipping>`).
- **PDF**: `Socia/socio: sì` text after "Ordini come"; row `Sconto soci -30%` / `-9,60 €` after "Copie"; total label from `orderTotalLabel(order.member)`. U+2212 is not WinAnsi, so `pdfText` maps it to `-` (else it prints `?`).
- **D1**: 0002 is two `ALTER TABLE orders ADD COLUMN` (they append after `notify_error`, so `ORDER_COLUMNS` appends `member`, `discount_cents` and keeps table order). Remote apply is the conductor's after the gate and before any deploy; until then an insert fails and the order reaches ordini@ by email only (200, not saved).
- **Tests (essential)**: `npx tsx` scripts in `$TMPDIR/borsa-V6/` (absolute imports, `node:assert/strict`, not committed); expected money strings built with `formatCents` (it emits U+00A0). Browser, D1 and servers are T4's (lesson: executors start no server).
