## The slice, decided here
- **"WAVE-level" locally = axe-core** in headless Chromium (Playwright 1.63, cached headless shell 1248, as V1/V2), tags `wcag2a wcag2aa wcag21a wcag21aa wcag22aa`, scoped to `main` (page) and `#bag-drawer` (drawer) so the dev toolbar, GA and Iubenda stay out. WAVE itself is a browser extension: the user runs it on the deployed pages (setup note checklist).
- **Detector**: `impeccable detect --json` on the surface sources and on the rendered DOM of each state (saved by the walk), from the repo root so `.impeccable/config.json` applies. A false positive is recorded in V3-ledger.md with its reason and becomes an `ignoreValues` entry in T3; anything else is a real finding.
- **Fix rule (T5)**: a real finding goes to one executor whose Files are only the files of that surface (listed under Files above); commit `Fix a11y finding on <drawer|borsa|success>: <what>`; then T5 re-runs that surface at both widths. T2 and T3 start after T5, so the docs describe the fixed state.
- **Setup order** (V2 closing notes): sender confirmed → Resend domain and DNS → WAF rule → Turnstile widget → `RESEND_API_KEY` and `TURNSTILE_SECRET_KEY` as Worker secrets → `PUBLIC_TURNSTILE_SITE_KEY` last, in `.env.cloudflare`, then `deploy:cf`. Until the site key is built in, `/borsa` shows the email box, so a half-done setup never shows a form that cannot send.
- **Resend domain = the domain of `ORDER_FROM`** (`src/lib/order.ts:132`, today `send.multimage.org`); the note says to copy record names and values exactly as Resend shows them, never to touch the apex MX (Google Workspace).
- **WAF**: one rate limiting rule (Free plan: one rule, 10 s period, 10 s block), expression `(http.request.uri.path eq "/api/ordine")`, counted per IP, 2 requests per 10 s, action Block (the Free plan likely accepts only Path and Verified Bot fields: no Method condition; GETs count too, harmless, they get 405; if the dashboard offers other periods or fields, keep 2 requests per 10 s; facts to confirm in the dashboard). Checked with bare `{}` POSTs, which answer 503 before any key exists and never send mail.
- **No secret values anywhere**: docs carry key names only; the note's commands read values at the `wrangler` prompt; the `.env.cloudflare` line is shown as `PUBLIC_TURNSTILE_SITE_KEY=<site key>`.
- **Docs language**: new and rewritten text in English, including the Italian book-page bullet of `current-state.md` that becomes false.
- **TODO.md**: four follow-ups (ids below) plus a Completed line for the borsa work.
