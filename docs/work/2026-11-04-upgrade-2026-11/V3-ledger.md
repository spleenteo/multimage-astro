## Close draft

Narrative: V3 put the repo on Node 24 (`.nvmrc` 24, `engines` 24.x), took every patch/minor in range (astro 6.4.8, @astrojs/vercel 10.0.8, @datocms/astro 0.6.16, content-link 0.3.23, cma-client 5.8.1, prettier 3.9.10 and the rest), held the datocms CLI on `~4.0.29` with an `overrides` guard keeping `@datocms/cli-utils` below 4.2 (4.2 pulls cma-client-node 6), pinned swiper at 12.1.4, moved to TypeScript 6.0.3 with `baseUrl` dropped from `tsconfig.json`, and added `.vercelignore`. The one surprise came in T2: cma-client 5.8 broke an ambient `declare module '@datocms/cma-client'` shim that re-exported generated paths that no longer exist, and deleting it alone gave 9 errors, because a second shim in `src/types/datocms.d.ts`, a script-file module declaration, was replacing the real module wholesale. The runner ruled to delete both and let the package's own types resolve; buildClient, Client, ApiError and ItemTypeDefinition all come from cma-client itself now, and the final review confirmed a single rest-client-utils copy so `instanceof ApiError` holds. TS 6 needed only the `baseUrl` removal; prettier 3.9 rewrote one file. The runner ran T6 itself on port 4333 (user at first stop): all published routes 200, `/staff` 404 without session, draft read and `/staff` with session 200; server stopped, schema.ts clean. Gate green. Five low findings from the final review were logged, not fixed: two stale doc sentences (caching.md:125 on `.nvmrc`, dependencies.md:32 "upgrade promptly" vs the 4.0.x hold), wording at current-state.md:102, TODO ordering, and a follow-up to pin `@types/node@^24`. Still to happen outside the checkout: the Vercel project's Node.js setting to 24.x (user), first seen on V4's preview.
Lessons:
- A `.d.ts` with `declare module 'x'` and no top-level import/export replaces package x's own types entirely: before editing or deleting one such shim, grep `src` for every `declare module 'x'` and treat them as one unit.
- Plain `tsc -p tsconfig.json` cannot resolve `.astro` imports (TS2307 on every component `index.ts`): judge a TypeScript or tsconfig change by `astro check`, never by plain `tsc` alone.
- A dev server log records the full `/api/draft-mode/enable?token=…` URL: write it to the scratchpad, print only redacted lines, delete it when the server stops.
Decision candidate: Rely on `@datocms/cma-client`'s own type declarations and delete the two ambient `declare module '@datocms/cma-client'` shims in `src/types/`, rather than updating the shims to the 5.8 paths (RawApiTypes/ApiTypes) or holding cma-client at 5.4.18.
