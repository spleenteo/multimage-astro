## Close draft

Narrative: V4 moved the site to Astro 7.4.7 and @astrojs/vercel 11.0.20 (vite 8.3.6, Rust compiler) with no template fix needed, and pinned `compressHTML: true`. Astro 7's `true` is not v6's: it keeps one space where the source has whitespace between elements, so the T1/T4 DOM diff showed word-splitting hunks only; they were accepted (block/flex or collapsing context) because `'jsx'` glued header words and `false` keeps everything. The ISR output changed as the adapter's changelog says (`x_astro_path_token`, `$1`, wrapped `src`, `/_astro` header before `filesystem`), plus the final catch-all losing `"status": 404`, which the server-rendered 404 page now sets (unknown path 404 on the preview). The preview deploy waited twice on entry checks: the Vercel project's Node setting was 22.x until the user changed it to 24.x (the build then skipped its cache on the version change), and the SSO-protected project had no automation bypass, so `vercel curl` created one under the user's authorization; revoking it is now TODO S7. On the preview: six smoke routes 200, `/staff` 404 before and after the editor session, both draft cookies with Secure/Partitioned/SameSite=None, the draft book served as BYPASS and the anonymous one as HIT with no badge; Preview `PUBLIC_SITE_URL` is production, so only the no-op revalidate ran. Found on the way: an unknown book slug returns 500 (also on production), now TODO BOOK-404.
Lessons:
- Before asserting that a newer framework's option "keeps vN output", diff a normalized DOM of real pages before and after: Astro 7 `compressHTML: true` keeps a space v6 dropped.
- A vercel deploy run under an agent prints JSON on stdout: take the URL from `.deployment.url`, not from the last line.
- zsh doesn't word-split an unquoted `$var`: `set -- $p` in a loop silently passes empty arguments; use a function with explicit arguments.
- Probe 404s with more than one shape of unknown path (top-level and under a dynamic route): a dynamic route that throws gives 500 where a top-level miss gives 404.
- `vercel curl` on a protected project with no automation bypass creates one silently on the project: record it in TODO for revocation the moment it is created.
Decision candidate: `compressHTML: true` kept over the Astro 7 `'jsx'` default (with a `{" "}` audit) and over `false` — already recorded in docs/decisions-log/2026-11-05-astro-7-upgrade.md; none new
