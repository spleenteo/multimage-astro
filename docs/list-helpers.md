---
scope: A list to describe all helpers, scripts, middlewares used in the project
---

- **`executeQuery`** (`src/lib/datocms/executeQuery.ts`)
  - Purpose: wraps `@datocms/cda-client`, automatically swapping the CDA token and `includeDrafts` flag when Draft Mode is enabled.
  - Used in: every GraphQL request (`BaseLayout`, pages, APIs).
  - Notes: throws descriptive errors if the required token is missing to avoid silent preview failures.
  - Cloudflare: when the middleware has opened the request tag store (`cacheTagStore`), published queries run through `rawExecuteQuery` with `returnCacheTags` and push the `x-cache-tags` into the store; draft queries mark it `disabled`. The optional `cacheTagScope: 'layout'` (BaseLayout only) flags the layout tags. It never calls `cache.set`; with no store (Vercel) nothing changes.
- **`draftMode` helpers** (`src/lib/draftMode.ts`)
  - Purpose: exposes `enableDraftMode`, `disableDraftMode`, `isDraftModeEnabled`, and `draftModeHeaders` so API routes and pages share the same logic.
  - Used in: `/api/preview`, `/api/draft-mode/*`, `BaseLayout`, and every page that needs to check whether previews are active.
  - Notes: relies on `SIGNED_COOKIE_JWT_SECRET` and the cookie name exported by `astro:env/client`. Page-level callers guard the helper with `import.meta.env.DEV` so prerendered builds never attempt to read cookies.
- **`draftPreview` utilities** (`src/lib/draftPreview.ts`)
  - Purpose: centralises Draft Mode resolution and exposes `resolveDraftMode(Astro)` for components/pages.
  - Used in: every CMS-driven page, BaseLayout, DraftModeQueryListener.
  - Notes: all routes are SSR with ISR; `resolveDraftMode` reads the signed draft-mode cookie so editors get drafts + Visual Editing while anonymous traffic serves from the CDN cache.
- **`commonFragments`** (`src/lib/datocms/commonFragments.ts`)
  - Purpose: exports shared `TagFragment`, `ResponsiveImageFragment` (full: base64 + srcSet, for hero/detail), and `RESPONSIVE_IMAGE_CARD_FIELDS` (lean raw fields, no base64/srcSet, for card/thumbnail grids).
  - Used in: most `_graphql.ts` files to keep fragments DRY.
  - Notes: card grids must pair `RESPONSIVE_IMAGE_CARD_FIELDS` with `<Image srcSetCandidates={[1,2]}>`. Book/Collection components rely on width/height—update carefully.
- **`recordInfo` helpers** (`src/lib/datocms/recordInfo.ts`)
  - Purpose: `recordToWebsiteRoute` and `recordToSlug` translate Dato records into site URLs/slugs. `index_page` records resolve by slug through the exported `INDEX_PAGE_PATHS` (shared with `revalidationUrls.ts`); `supplier` resolves to `/distributori`.
  - Used in: `/api/preview-links`, `/api/seo-analysis`, and any future automations that need to resolve routes.
  - Notes: extend the switch statements whenever you add a routable model so preview links stay accurate; keep the surgical revalidation map (`revalidationUrls.ts`) in sync with the same api_key → route table (index paths are shared via `INDEX_PAGE_PATHS`).
- **`publicUrls` helper** (`src/lib/datocms/publicUrls.ts`)
  - Purpose: `getAllPublicUrls()` enumerates every public URL (static + catalogue pages + record detail URLs) for the full-revalidation sweep.
  - Used in: `/api/revalidate?mode=full`.
  - Notes: dedupes against `STATIC_URLS`; per-publish revalidation uses `revalidationUrls.ts` instead.
- **`cacheTags` helper** (`src/lib/datocms/cacheTags.ts`)
  - Purpose: per-request cache tag collection (Cloudflare only). Exports `cacheTagStore` (AsyncLocalStorage), `createCacheTagState`, `addCacheTags` (parses an `x-cache-tags` header), `decidePageTags` (tags, or the coarse `site` fallback on empty, overflow, invalid, no-layout or draft), `isValidCacheTag`, and the constants `SITE_TAG`, `MAX_PAGE_TAGS` (990) and `COARSE_MAX_AGE` (1 day).
  - Used in: `src/middleware.ts` (opens the store, makes the one final `cache.set`), `executeQuery`, `cacheInvalidation.ts`.
  - Notes: pure module, no env or network; checked by `npm run check:cache-tags`.
- **`cacheInvalidation` helper** (`src/lib/datocms/cacheInvalidation.ts`)
  - Purpose: pure helpers of the invalidation endpoint. `invalidationTags(payload)` reads `entity.attributes.tags` (null when malformed; valid deduped tags plus `site`, with a `dropped` count); `purgeInBatches(tags, purge)` purges in sequence, `PURGE_BATCH_SIZE` (100) tags per call, stopping at the first failure. Types `PurgeFn`, `CachePurgeResult`.
  - Used in: `POST /api/invalidate-cache` (Bearer `CACHE_INVALIDATION_WEBHOOK_SECRET`, Cloudflare only: 503 elsewhere).
  - Notes: the purge function is injected, so it runs under plain `tsx`; checked by `npm run check:cache-tags`.
- **`siteSearch` helper** (`src/lib/datocms/siteSearch.ts`)
  - Purpose: `reindexSiteSearch(logPrefix)` triggers the Site Search build trigger through the CMA; best-effort, returns false (no throw) when the tokens are missing or the call fails.
  - Used in: `/api/revalidate`, `/api/invalidate-cache`.
  - Notes: needs `DATOCMS_CMA_TOKEN` and `SITE_SEARCH_BUILD_TRIGGER_ID`; imports `astro:env/server`, so it does not load under plain `tsx`.
- **Cache-tags check** (`check.ts` in scripts/cache-tags)
  - Purpose: no-network check of `decidePageTags`, `addCacheTags`, `invalidationTags` and `purgeInBatches` (stub purge function), printing `OK`/`MISMATCH` per case.
  - Used in: `npm run check:cache-tags`.
  - Notes: runs with the same sentinel preload as the revalidation-map check, which blocks `fetch`.
- **`revalidationUrls` helper** (`src/lib/datocms/revalidationUrls.ts`)
  - Purpose: `getRevalidationUrls({ apiKey, slug, id }, query?)` maps a changed record to the small set of affected URLs (surgical revalidation). Book changes enrich with catalogue pages + the book's authors'/collection's detail pages via one CDA query (injectable through the `query` parameter, default `executeQuery`). `index_page` maps by slug to its index URL; `supplier` to `/distributori`; `license` (id) to the pages of the books carrying it (the license renders only on the book page); `app` is a deliberate no-op.
  - Used in: `/api/revalidate` (surgical mode).
  - Notes: unknown/unmapped models return `[]` (caller no-ops); never throws (degrades to the bounded static set). Index paths come from `INDEX_PAGE_PATHS` in `recordInfo.ts`.
- **Revalidation-map check** (`check.ts`, `scripts/revalidation-map/stub-execute-query.mjs`, `scripts/revalidation-map/sentinel.mjs`)
  - Purpose: `check.ts` (in scripts/revalidation-map) is a no-network check that runs `parseWebhookPayload` + `getRevalidationUrls` on sample payloads (the `payloads` folder beside them), tests `recordToWebsiteRoute` through a route table, and reports `OK`/`GAP`/`MISMATCH`; the stub is passed directly as the `query` argument (no module hooks), and the `.mjs` files are only the stub and the sentinel.
  - Used in: `npm run check:revalidation-map` (procedure (a) in `docs/guidelines/caching.md`).
  - Notes: includes the V2 cases (`index_page`, `supplier`, `license`, `app`).
- **`webhookPayload` parser** (`src/lib/datocms/webhookPayload.ts`)
  - Purpose: pure `parseWebhookPayload()` extracting `event_type`, record `id`, record `slug`, and model `api_key` from a DatoCMS webhook (payload API v3).
  - Used in: `/api/revalidate`.
  - Notes: no env/network deps so it is unit testable; reads the item_type from `related_entities`.
- **`structuredText` helpers** (`src/lib/datocms/structuredText.ts`)
  - Purpose: converts Structured Text to plain text, checks emptiness.
  - Used in: SEO fallbacks, author summaries, info pages.
  - Notes: safe alternative to `toRichTextHtml` when sanitization is required.
- **`structuredTextComponents`** (`src/lib/datocms/structuredTextComponents.ts`)
  - Purpose: maps Structured Text blocks, inline records (`defaultInlineRecordComponents`), record links and node overrides (`defaultNodeOverrides`: plain links) to Astro components.
  - Notes: update this registry whenever components change (keep docs/list-components.md aligned).
- **`structuredTextHeadings`** (`src/lib/datocms/structuredTextHeadings.ts`)
  - Purpose: `shiftHeadings(field, top = 2)` shifts every heading of a Structured Text value so the highest becomes h2 (editors often start at h3); returns a copy.
  - Used in: `/magazine/[slug]`.
- **`recordUrls`** (`src/lib/recordUrls.ts`)
  - Purpose: `recordPath(typename, slug)`, the public path of a linked record (`AuthorRecord` → `/autori`, `BookRecord` → `/libri`, `CollectionRecord` → `/collane`, `PageRecord` → `/info`, `BlogPostRecord` → `/magazine`); `toSitePath(url)` makes multimage.org URLs relative.
  - Used in: `LinkToRecord`, `InlineRecordBlock`, the Structured Text `Link` override.
- **`magazine` helpers** (`src/lib/magazine.ts`)
  - Purpose:
    - `postDate` (`_firstPublishedAt`, then `createdAt`);
    - `formatPostDate`;
    - `categoryLabel(category, 'plural' | 'singular' | 'others' | 'all')`: normalised labels by slug, `news` → "Notizie", with agreement ("Altri eventi", "Tutte le recensioni");
    - `categoryHref` (`/magazine?categoria=<slug>`).
  - Used in: `/magazine`, `/magazine/[slug]`, `MagazinePostCard`.
- **`text` utilities** (`src/lib/text.ts`)
  - Purpose: `toPlainText`, `truncateToLength`, `withoutUrls` (drops bare URLs from plain text), entity decoding, `toRichTextHtml`.
  - Used in: book hero copy, supplier bios, staff notices.
  - Notes: `toRichTextHtml` trusts HTML; see Security task **S2**.
- **`books` helper** (`src/lib/books.ts`)
  - Purpose: builds book view models, formats price/edition/licence/year, exposes `buildEditionDetails` + `buildGraphicsDetails`, `buildOrderMailto` (prefilled `mailto:ordini@multimage.org` for one book: subject, title, authors, ISBN, price, copies, address), `ebookStoreName` (store label from an ebook URL, "Bookrepublic"), and owns the catalogue-pagination source of truth: `BOOKS_PER_PAGE`, `booksCataloguePageCount(total)`, `buildBooksCataloguePaths(total)`.
  - Used in: listings, carousels, detail pages, staff exports, printable schede; `/libri` route, sitemap, `publicUrls.ts`, `revalidationUrls.ts`.
  - Notes: `mapBooksToCards` is the canonical adapter for `BookCard` props. Keep `BOOKS_PER_PAGE` here so route/sitemap/revalidation agree on page count.
- **`authors` helper** (`src/lib/authors.ts`)
  - Purpose: formats author names, chips, sort letters, and related metadata.
  - Used in: `/autori`, book detail sidebars, Structured Text.
  - Notes: exposes `AUTHOR_NAME_FALLBACK`, `buildAuthorSegments`, etc.
- **`suppliers` helper** (`src/lib/suppliers.ts`)
  - Purpose: converts Dato supplier records into card view models and region groups.
  - Used in: `/distributori`.
  - Notes: generates Google Maps URLs and rich-text HTML strings that must be sanitized (Security task **S2**).
    - `parseSupplierPhones(raw)` pulls every number out of the free-text phone field ("Tel … - Fax …", "Nome tel. …", "011.188…-347.…") and formats it the Italian way. It returns a `tel:+39…` href and the person's name when given. Unparseable text is kept.
    - `supplierWebsiteLabel(url)` returns "Facebook"/"Instagram" or the bare host.
- **`colors` helper** (`src/lib/colors.ts`)
  - Purpose: derives palette colors from Imgix metadata and blends shades (`pickBaseColor`, `lightenColor`, `darkenColor`, `hexToRgba`); `contrastRatio` (WCAG ratio) and `readableTextOn` (charcoal or white, whichever reads better on a tinted background); `coverFieldPalette(colors)` returns the Book Cover Field set (field 16%, copy half 88%, cover shadow, caption colour).
  - Used in: `BookCard`, `FeaturedBookHighlight`, `BannerSection`, `HomeHero`, `libri/[slug]`, color-aware UI.
- **`catalogue` helper** (`src/lib/catalogue.ts`)
  - Purpose: rules of the faceted `/libri` catalogue shared by server and browser: `CatalogueEntry` (compact per-book facet record), `matchesCatalogue` (with an `ignore` facet for option counts), `parseCatalogueState`/`serializeCatalogueState` (URL), `buildPeriodOptions`, `isTranslated`, `normalizeForSearch`, `CATALOGUE_CHUNK` (40), `CatalogueCard` (a card as `/catalogue-books.json` serves it) and `CATALOGUE_CARDS_URL`.
- **`bookCardView` helper** (`src/lib/bookCardView.ts`)
  - Purpose: `bookCardView(input)` works out what a book card shows (link, meta line, price label, tinted field, cover URLs and the `Book3D` input). Used by `BookCard` and by `toCatalogueCard`.
- **`book3d` helper** (`src/lib/book3d.ts`)
  - Purpose: `book3dView(input)` turns cover size, page count, colours and pose into the inline variables of `Book3D`, and says which side face and page edge the pose shows.
- **`authorIndex` helper** (`src/lib/authorIndex.ts`)
  - Purpose: `buildAuthorIndex(records, books)` builds the `/autori` items (`AuthorIndexItem`: name, size line, one-line bio, portrait, up to 4 small covers, letter group, search text) for authors with at least one book. Used by the page (letters `AUTHORS_SERVER_LETTERS`) and by `/authors-index.json` (everyone).
- **`catalogueCard` helper** (`src/lib/catalogueCard.ts`)
  - Purpose: `toCatalogueCard(record)` builds a `CatalogueCard` for `/catalogue-books.json` from `bookCardView` and `book3dView`, so cards built in the browser match the server-rendered ones.
  - Used in: `/libri`, `BooksCatalogue`.
- **`currency` helper** (`src/lib/currency.ts`)
  - Purpose: formats `EUR` values (`it-IT`).
  - Used in: `BookCard`, staff exports.
- **`seo` helper** (`src/lib/seo.ts`)
  - Purpose: attaches fallback `<title>`/`<meta name="description">` tags when `_seoMetaTags` omit them.
  - Used in: every page via `withFallbackSeo`.
- **Dato type exports** (`src/lib/datocms/types.ts`)
  - Purpose: centralizes reusable TypeScript aliases for Dato records.
  - Notes: regenerate via `npx datocms schema:generate`; never edit manually.
- **Search client** (`src/pages/cerca/search-page.client.ts`)
  - Purpose: browser-only module powering `/cerca` (debounce, filters, URL sync, rendering).
  - Notes: bundled by `scripts/build-search-client.mjs`; `getRootConfig` throws if required `data-*` attrs are missing. Tests tracked under docs/TODO.md task **TC2**.
- **Search styles** (`src/pages/cerca/_search.css`)
  - Purpose: global CSS for `/cerca` — covers static page elements and dynamically-created result cards.
  - Notes: imported in `index.astro` frontmatter so it is not scoped; class names must match those set in `search-page.client.ts`.
- **Staff CSV exporter** (inline inside `src/pages/staff/archivio-catalogo/index.astro`)
  - Purpose: turns the prerendered `<table>` into a downloadable CSV with BOM.
  - Notes: slated for extraction + testing (Code Health task **CH1**).
- **Search/Swiper bundler** (`scripts/build-search-client.mjs`)
  - Purpose: builds `public/generated/search-page.client.js` and `swiper-element.js` via esbuild.
  - Notes: deletes stale artefacts and honors `NODE_ENV` for sourcemaps.
- **`docs:inventory` checker** (`scripts/check-docs-inventory.mjs`)
  - Purpose: scans `src/components/**` + helper directories and verifies `docs/list-*` includes every component/helper path.
  - Notes: fails `npm run docs:inventory` when entries drift; keep bullets aligned with the script’s parsed format.
- **Dato sync script** (`scripts/sync-datocms.mjs`)
  - Purpose: loads env and regenerates `schema.ts`.
  - Notes: requires `DATOCMS_API_TOKEN` or `DATOCMS_CMA_TOKEN` to run schema generation (schema generation only — no external doc download).
- **`newsletter` helper** (`src/lib/newsletter.ts`)
  - Purpose: provides the newsletter CTA copy/link data (Brevo) used by the site-wide newsletter section.
  - Used in: `NewsletterCta` component / BaseLayout footer area.
- **API response helpers** (`src/pages/api/utils.ts`)
  - Purpose: shared `withCORS`, `json`, `invalidRequestResponse`, `successfulResponse`, and `isRelativeUrl` utilities for every API route.
  - Used in: `/api/preview`, `/api/preview-links`, `/api/seo-analysis`, `/api/post-deploy`, etc.
  - Notes: keep `withCORS` in sync with Dato plugin requirements and reuse `isRelativeUrl` for any new redirect-bearing endpoints.

- `bookPose(key)` / `bookSpineColors(colors)` — `src/lib/bookPose.ts`. Deterministic hover pose for `Book3D` from a book slug (side, angles, offset, scale: random-looking across a grid, stable across visits and cache), and spine/band/ink colours from the cover's palette.
